# MineColonies: Universal Resources

MineColonies: Universal Resources is an addon for MineColonies that makes gathering construction materials much easier
and far less grindy.

Instead of collecting and crafting hundreds of individual blocks, this mod introduces set of new resource items that
will be used as replacement for many building requirements.

Simply craft the required amount of these items, and they'll satisfy the building material requirements. Spend less time
crafting endless possibilities of blocks and more time expanding your automatization and colony.

## Why?

I never liked how you need to craft in all sort of different ways required blocks to build/upgrade buildings. It was too
boring and grindy

## Disclaimer

Mod still early in development and probably unbalanced and buggy. Feel free to report any issue or request feature.
